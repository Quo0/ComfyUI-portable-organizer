# Чистка репозитория от русского

Временный документ. Живёт до конца работ и удаляется последним шагом
Фазы 6 — вместе с этим предложением.

Цель: в версионируемых файлах не остаётся русского текста, кроме явно
перечисленных исключений. Комментарии и заметки либо переводятся
на английский, либо удаляются — по области, а не по вкусу.

---

## Что не трогаем никогда

Список закрытый. Всё, чего в нём нет, попадает под чистку.

| Что | Почему |
|---|---|
| `PLAN.md`, `plan/**` | выносится из репозитория целиком отдельной задачей |
| `specs/**` | там же, по той же причине |
| `apps/docs/ru/**` | русская локаль сайта документации — продукт, а не заметки |
| `apps/desktop/src/i18n/locales/ru.json` | русская локаль интерфейса, источник — `en.json` |
| `apps/design/**/*.md` | содержимое витрины, а не комментарии; решение от 2026-08-28 — оставить как есть |
| история git | сообщения коммитов по-русски остаются; переписывать историю не будем |
| тело релиза `v0.1.0` на GitHub | опубликовано; перевод `CHANGELOG.md` его задним числом не меняет |

**Локали — не комментарии.** Ни одна фаза не имеет права тронуть
`ru.json` и `apps/docs/ru/`. Это единственная ошибка в этой работе,
которая ломает продукт, а не документацию.

## Разрешённая остаточная кириллица

Выяснилось на Фазе 1: «ноль кириллицы» — недостижимый и неправильный
критерий. Русские буквы остаются там, где они не заметка, а данные
или адрес. Три вида, и других быть не должно:

1. **Указатели в русские файлы.** Скилы и агенты ссылаются на разделы
   `plan/` и `specs/`, которые остаются русскими: метка `Теги:`, блок
   «Негативные и краевые случаи», колонка «Статус», раздел «Дисциплина
   z-order», пункты меню витрины «Стайлгайд» и «Экраны». Перевести —
   значит сломать указатель.
2. **Тестовые данные с не-ASCII.** `_архив`, `стенд с пробелом`,
   `старое-fake.safetensors`, пример пути `Модели ИИ`. Это и есть
   проверяемый случай: квотирование при спавне, кодировка консоли,
   разбор YAML. Перевод здесь удаляет проверку, а не переводит её.
3. **Образцы переводов.** Примеры вызова `i18n-add` и формы
   множественного числа в скиле `i18n` — русский там демонстрируемый
   материал. Плюс ссылка `[Русский]` в README: это переключатель языка,
   а не текст.

Замер поэтому сверяется не с нулём, а с этим списком: любая новая
строка — нарушение, любая из перечисленных — норма.

## Как считаем прогресс

Замер на любой момент — число строк с кириллицей по области:

```
git ls-files <область> | xargs -r grep -hc '[А-Яа-яЁё]' | awk '{s+=$1} END {print s+0}'
```

|---|---:|---|

## Открытый вопрос, решаемый по ходу

В `apps/desktop/src` часть комментариев фиксирует капканы, а не
пересказывает код: почему замер идёт после показа контейнера, почему
у Layout-компонентов стиль без `scoped`, почему вкладка не перекрывается
модалкой. По твоей раскладке они удаляются вместе с остальными.

Риск: знание теряется молча и покупается второй раз. Смягчение без
расширения объёма — такие комментарии не удалять, а сворачивать
в английскую строку-другую. Помечаю их по ходу Фазы 2 списком ниже
и решаем разом, а не по каждому файлу.

- [ ] Список комментариев-капканов из `apps/desktop/src` собран
- [ ] Решение принято: удалить / перевести

- **Русский блок в `NOTICE` удалён целиком**, а не переведён: он был

- **Роли палитры в `tools/lib/style-tokens.mjs` теперь английские**,
  а витрина, которая их показывает, осталась русской: в разделе

  Осознанное следствие решения не трогать `apps/design/**/*.md`.
- **Критерий «ноль кириллицы» заменён** списком разрешённой остаточной
  — см. раздел выше.
