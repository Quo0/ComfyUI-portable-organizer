# Wizard steps

<!-- US-INST-01 · US-INST-05 -->

Five steps the user can leave at any moment without leaving anything behind.

Numbering is justified here: this is a real sequence where the order carries
meaning — until an archive is chosen there is no disk space to check, and until
the folders are set there is nothing to unpack.
