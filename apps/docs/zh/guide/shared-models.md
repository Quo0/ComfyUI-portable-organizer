# 共享模型

每个便携版整合包都带着自己的 `ComfyUI\models\`。一个大模型 2 到 20 GB，
三四个整合包就意味着几百 GB 的相同文件。ComfyUI 恰好为此准备了一套机制
——`extra_model_paths.yaml`——而应用的工作，就是生成一份正确的配置并交给
整合包。

## 文件夹怎么摆

在所有整合包之外、空间充裕的盘上选一个文件夹：

```
D:\AI\_shared_models\
├─ checkpoints\
├─ loras\
├─ vae\
├─ controlnet\
├─ upscale_models\
├─ embeddings\
├─ text_encoders\        （或 clip\）
└─ diffusion_models\     （或 unet\）
```

然后打开 **设置 → 共享模型**，选中这个文件夹，应用会扫描它。

**分类是按真实存在的子文件夹生成的**，不是照着一份写死的类别清单。这是
有意的：ComfyUI 会在版本之间增加模型类型，冻结在我们代码里的清单迟早会
过时。加一个子文件夹，重新扫描，它就会出现在配置里。

有两个旧名字已经替你映射好了：`unet\` 归到 `diffusion_models`，`clip\`
归到 `text_encoders`，这也是 ComfyUI 内部的做法。旧的和新的文件夹可以
同时存在，两者最终会落到同一个键下。

应用不认识的子文件夹会单独列出来，而不是悄悄丢掉——你能看到什么被落下了。

`custom_nodes` 被无条件排除，尽管这个键是合法的，也出现在 ComfyUI 自带的
示例文件里。共享自定义节点会推翻整合包分开存放的理由：它们彼此冲突，一个
共享文件夹会把它们一次全弄坏。

## 你本地的模型不会被取代

这些路径是**叠加**的。ComfyUI 会把额外路径追加到整合包已有的路径后面，
所以整合包里原有的模型和以前一样能用。连接一个文件夹不会把任何东西搬到
别处。

**“将新模型下载到共享文件夹”** 这个开关只管一件事：共享文件夹是否排在
列表的最前面——ComfyUI Manager 会把新下载的文件放到那里。它不影响能找到
什么。

## 连接一个整合包

在整合包的**模型**标签页上有个开关。打开它，整合包就会从下次启动起使用
共享文件夹。运行中进程的参数是改不了的，所以应用会直接说明需要重启，而
不是假装开关已经生效。

## 两种应用方式

**参数模式——默认。** 生成的 YAML 放在应用自己的数据目录里，启动时把
`--extra-model-paths-config <路径>` 加到命令行上。你的整合包里什么都不会
被写入。关掉它只是取消一个勾选；一份配置服务所有整合包，也只在一个地方
维护。

**文件位于整合包内。** 应用会写入
`<整合包>\ComfyUI\extra_model_paths.yaml`。如果你有时会绕开应用、直接用
`.bat` 启动整合包，就选这个模式：ComfyUI 会自己读到这个文件。

这个模式下的冲突策略很严格：

- 那里没有文件 → 写入；
- 那里是我们的文件（靠文件头里的标记行识别） → 重写；
- **那里是别人的文件 → 不动它。** 你会看到一个对比页面，原文件备份为
  `extra_model_paths.yaml.bak-<时间戳>`，只有在你确认之后才会替换。同一个
  页面上给出的另一个选择是：别动它，改用参数模式。

在这个模式下断开连接，会删掉我们的文件，并在有备份时把它恢复回去。

## 如果文件夹不在

没插上的移动硬盘会在整合包启动**之前**就被发现，并提供不带共享模型启动的
选项。在生成到一半时靠 “model not found” 才知道，不是一个选项。

## 把模型移进共享文件夹

整合包的**模型**标签页会列出这个整合包里有什么，以及共享文件夹里已经存在
的同名同大小的文件。

- **移动到共享文件夹** 会复制文件、把副本读回来、比对，然后才删除原件。
  在副本通过校验之前，原件一直待在原地。
- **删除本地副本** 会从整合包里删掉共享文件夹中已有的文件——同样是在确认
  那个双胞胎确实在场之后。

这两项在运行中的整合包上都会拒绝执行：ComfyUI 打开着那些文件，并且在启动
时就解析好了自己的路径。

没有你的要求，什么都不会被删除，而且在东西离开之前，会明确告诉你要走的是
哪些。

## 确认它真的生效了

最直接的检查完全不经过界面。在整合包运行时打开
`http://127.0.0.1:<端口>/internal/folder_paths`——它会列出每个类别以及背后
的路径，共享文件夹也在其中；打开“将新模型下载到共享文件夹”后，共享路径会
排在自己那一组的最前面。

启动日志会同步显示同样的事情：ComfyUI 每接手一个路径，就记下一行
`Adding extra search path checkpoints D:\…`。
