# SmartScreen 提示

运行安装程序时，Windows 会弹出一个蓝色窗口：

> **Windows 已保护你的电脑**
> Microsoft Defender SmartScreen 阻止了无法识别的应用启动。运行此应用
> 可能会使你的电脑面临风险。

**仍要运行** 按钮藏在 **详细信息** 后面。

## 它为什么会出现

安装程序没有用代码签名证书签名。SmartScreen 不认识发布者，于是发出警告
——和它对任何小型开发者的新程序所做的一样。

没有不花钱的绕过办法：

- **Azure Trusted Signing** 这条便宜的路，只对组织，以及在美国和加拿大
  注册的个体经营者开放。
- 普通的 OV 证书每年要几百美元，**而且** 仍然需要先积累信誉，警告才会
  不再出现。

所以应用就这样不签名地发布，取而代之的是这一页。把这件事藏起来，比警告
本身更糟。

## 该点什么

1. 点击 **详细信息**。
2. 确认发布者一行写的是 *未知发布者*，文件名就是你下载的那一个。
3. 点击 **仍要运行**。

## 与其信任它，不如校验它

每个发布版本都会在安装程序旁边附一份 `SHA256SUMS.txt`。把你下载的文件的
哈希值和其中记录的比对一下：

```powershell
Get-FileHash '.\ComfyUI Portable Organizer_0.1.0_x64-setup.exe' -Algorithm SHA256
```

两个字符串一致，说明这个文件与发布流程从公开源码构建出来的那一份逐字节
相同。如果不一致，删掉重新下载——而且只从
[发布页面](https://github.com/Quo0/ComfyUI-portable-organizer/releases)
下载，别处一律不要。

## 不过，更新是签名的

应用内更新带有自己的签名，并且在安装任何东西之前就会验证：一对 `minisign`
密钥，公钥那一半编译进了应用里。验证不通过的更新不会被安装，并且会告诉你
原因。

这个签名证明更新来自我们，它和 SmartScreen 无关——不同的机制，不同的
问题。
