# 卸载

从 **设置 → 应用 → 已安装的应用** 卸载，走 Windows 的常规流程。不需要
管理员权限，因为这个应用本来就装在你的用户目录里。

卸载程序会问你要不要连应用数据一起删掉。

## 什么会消失

| 勾选“删除应用数据” | 会被删除 |
| --- | --- |
| 应用本身 | 总是 |
| `%APPDATA%\io.github.quo0.comfyui-organizer` —— 设置、整合包注册表、工作流库路径 | 仅勾选时 |
| `%LOCALAPPDATA%\io.github.quo0.comfyui-organizer` —— 缓存与 WebView2 数据 | 仅勾选时 |

不勾选这个框，你的注册表和设置就会留下，以后重新安装会照原样把它们接回来。

## 什么会始终留下

- **你的模型。** 共享文件夹里的，以及每个整合包内部的，都算。
- **你的工作流库**，包括它的 `_library.json`。
- **ComfyUI 整合包本身。** 注册表从头到尾只记住了它们在哪儿。
- **应用写进你整合包里的那两类文件**，如果你要求过的话：“文件位于整合包
  内”模式下的 `ComfyUI\extra_model_paths.yaml`，以及你添加到某个整合包里
  的工作流副本。它们位于别人的整合包里，我们无权清理。

这些内容在你卸载之前，就都列在应用自己的 **关于** 页面上——每个路径旁边
都有一个按钮，能在资源管理器里打开它。

## 从不悄悄删除任何东西

应用只在三种情况下删除属于你的内容，每一种都由你点击开始，并且在此之前
已经告诉过你什么会消失：

1. **把模型移到共享文件夹** —— 只有在副本写好、读回并比对之后，原件才会
   被删除。
2. **删除重复的模型** —— 只删那些已核实确实存在于共享文件夹中的文件。
3. **把工作流取入库中** —— 和模型一个顺序：复制、校验，然后删除。

除了这三种，你的东西一概不动。

## 事后手动清理

如果你当时没勾那个框，后来又改了主意，删掉这两个文件夹：

```
%APPDATA%\io.github.quo0.comfyui-organizer
%LOCALAPPDATA%\io.github.quo0.comfyui-organizer
```

再没有别的了。应用不往 `文档` 里写任何东西，不往 `%PROGRAMDATA%` 里写
任何东西，除了安装程序为卸载项建立的那条记录之外，也不往 Windows 注册表
里写任何东西。
