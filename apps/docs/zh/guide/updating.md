# 更新应用

应用会在启动时检查新版本，并把结果连同该版本的更新说明一起显示在
**关于** 里。

## 这项检查是唯一离开你电脑的东西

它把当前的版本号发给 GitHub，问一句有没有更新的发布。除此之外，关于你、
你的整合包和你的文件，没有任何内容会被发往任何地方。

它可以关掉：**关于 → 启动时检查更新**。关掉之后它就完全不运行了——没有
第二套藏起来的计划任务。你仍然可以随时按 **立即检查**。

没有网络时，什么都不会发生，也不会报告什么。一个你没要求过的网络错误看
起来就像应用坏了，而应用没坏；缺的是你的网络连接。

## 没有你，什么都不会安装

更新只有在你按下按钮之后才会下载和安装。安装任何东西之前都会先验证它的
签名，验证不通过的更新不会被安装——并且会告诉你原因。这个签名是一对
`minisign` 密钥，公钥那一半编译在应用里；它和
[SmartScreen 提示](/zh/guide/smartscreen)毫无关系，那是完全另一套机制。

## 运行中的整合包由你决定

安装更新会关闭应用——Windows 的安装程序就是这么工作的——所有正在运行的
ComfyUI 服务器也会跟着走，因为它们是应用的子进程。

所以只要还有东西在跑，安装就不会开始。你会拿到一份运行中整合包的清单和
两个选项：

- **停止它们并安装** —— 服务器被妥善停止，然后更新照常进行；
- **推迟到下次启动** —— 现在什么都不发生，下次你打开应用时，同一个更新
  会再提示一遍。

你的生成队列，比落后一个版本一小时更值钱。

## 你的数据能挺过更新

在旧版本上安装新版本走的是更新模式，它会完全跳过数据清理。设置、整合包
注册表、共享文件夹的连接和工作流库，都还在你留下它们的地方。

手动更新也是一样：下载新的安装程序，在旧版本上运行它。
