# Todavía no hay traducción

La documentación de ComfyUI Portable Organizer solo existe en inglés por
ahora. La aplicación en sí está traducida por completo: español, ruso y
chino simplificado vienen incluidos y se cambian en
**Ajustes → Apariencia**.

Esta dirección está fijada de antemano y no cambiará cuando llegue la
traducción: el enlace que compartas hoy seguirá funcionando entonces.
