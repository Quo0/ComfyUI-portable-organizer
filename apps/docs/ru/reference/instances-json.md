# `instances.json`

Реестр сборок. Обычный JSON в
`%APPDATA%\io.github.quo0.comfyui-organizer\instances.json`, под
единственным ключом `instances`.

Это список указателей. В нём никогда не бывает ни моделей, ни воркфлоу,
ни чего-либо ещё, скопированного из ваших сборок, — только то, где какая
сборка лежит и как вы её подписали.

```json
{
  "instances": [
    {
      "id": "i1750000000000",
      "name": "SDXL stable",
      "description": "Та, что работает",
      "path": "D:\\AI\\comfy-sdxl",
      "accent": "azure",
      "preferredPort": 8188,
      "comfyVersion": "0.3.62",
      "pythonVersion": "3.12.10",
      "createdAt": 1750000000000,
      "lastStartedAt": 1750600000000,
      "shared": { "enabled": true, "applyMode": "flag" },
      "customProfiles": [
        {
          "id": "custom:1",
          "name": "SDXL, мало VRAM",
          "baseId": "run_nvidia_gpu.bat",
          "args": ["-s", "ComfyUI\\main.py", "--lowvram"]
        }
      ],
      "source": {
        "archivePath": "D:\\downloads\\ComfyUI_windows_portable_nvidia.7z",
        "archiveLabel": "ComfyUI_windows_portable_nvidia.7z",
        "installedAt": 1750000000000
      }
    }
  ]
}
```

## Поля

| Поле | Значение |
| --- | --- |
| `id` | Выдаётся один раз и больше никому не достаётся. На него ссылается манифест библиотеки воркфлоу. |
| `name`, `description` | Ваши. Не переводятся и не додумываются. |
| `path` | Абсолютный путь к корню сборки — папке с `python_embeded\` и `ComfyUI\`. |
| `accent` | Имя токена палитры (`azure`, `moss`, …) или ваш собственный цвет как `#rrggbb`. |
| `preferredPort` | При запуске пробуется первым; если занят, берётся следующий свободный. |
| `comfyVersion`, `pythonVersion` | Читаются при регистрации, нужны только для показа. |
| `createdAt`, `lastStartedAt` | Миллисекунды с начала эпохи. До первого запуска `lastStartedAt` нет вовсе. |
| `shared` | `enabled` плюс `applyMode`: `flag` или `instanceFile`. См. [Общие модели](/ru/guide/shared-models#два-способа-применения). |
| `customProfiles` | Профили, которые вы собрали поверх разобранного. `baseId` — тот `.bat`, который они расширяют. |
| `source` | Появляется, если сборка приехала из мастера распаковки. |

У полей, которые появились в более поздних версиях приложения, есть
значения по умолчанию. Поэтому реестр, записанный старой версией,
читается без возражений — и, что важнее, ничего другого в нём при этом
не сбрасывается.

`available` в файле не хранится: существует ли ещё папка, приложение
проверяет заново при каждом чтении реестра.

## Правка руками

Пока приложение закрыто, править файл ничто не мешает. Он маленький,
пути в нём абсолютные, и починить в нём переехавшую сборку быстрее, чем
кликать. Помнить надо о двух вещах: в `path` обратные слэши
экранируются, как того требует JSON, а `id`, на который ссылается ваша
библиотека воркфлоу, без нужды менять не стоит.
