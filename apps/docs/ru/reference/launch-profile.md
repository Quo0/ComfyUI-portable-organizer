# Профили запуска

Профиль — это то, что означает один `.bat`-файл, в виде, пригодном для
прямого запуска. Профили выводятся из диска заново при каждом запуске:
источник правды — сами `.bat`-файлы, и они не изменяются никогда.

## Из чего он состоит

| Поле | Значение |
| --- | --- |
| `id` | Путь к `.bat` относительно корня сборки. Он же — его личность: `run_nvidia_gpu.bat`, `advanced\run_nvidia_gpu_disable_api_nodes.bat`. |
| `name` | Имя файла без расширения. Не переводится. |
| `advanced` | Пришёл из подпапки `advanced\`. |
| `pythonPath` | Абсолютный путь к интерпретатору, который вызывает строка. |
| `args` | Аргументы, разобранные на токены, с учётом кавычек. |
| `cwd` | Папка самого `.bat`-файла. |
| `env` | Переменные из строк `set КЛЮЧ=ЗНАЧЕНИЕ` выше команды. |
| `fallback` | Разбор не удался; файл будет запущен через `cmd /c`. |

Ваши собственные профили переиспользуют всё от базового и заменяют только
`args` — см. [`instances.json`](/ru/reference/instances-json).

## Как читается файл

`echo`, `pause`, `rem` и пустые строки пропускаются. Строки
`set КЛЮЧ=ЗНАЧЕНИЕ` становятся переменными окружения. Первая настоящая
командная строка разбирается на токены с учётом кавычек, исполняемый файл
становится `pythonPath`, остальное — `args`.

Относительные пути — включая `..\` в `advanced\*.bat` — разрешаются
относительно папки `.bat`-файла, потому что именно это происходит при
двойном клике по нему. Она же становится рабочим каталогом.

Профили, которые сервер не поднимают, например скрипты обновления
из пакета, в список запуска не попадают.

## `fallback: true`

Когда строку разобрать не удалось, профиль не выбрасывается: он
помечается как запасной и запускается через `cmd /c`. Интерфейс об этом
сообщает, потому что такой путь ставит между приложением и Python лишний
`cmd.exe` и делает остановку процесса менее надёжной.

## Пути, выведенные из аргументов

Три папки не предполагаются, а вычисляются из аргументов, по тому же
приоритету, которым пользуется сам ComfyUI:

| Папка | Какие флаги смотрим, по порядку |
| --- | --- |
| Модели | `--base-directory`, иначе `<сборка>\ComfyUI\models` |
| Данные пользователя (здесь живут воркфлоу) | `--user-directory`, затем `--base-directory`, иначе `<сборка>\ComfyUI\user` |
| Вывод | `--output-directory`, затем `--base-directory`, иначе `<сборка>\ComfyUI\output` |

Поэтому «открыть папку вывода» и «добавить воркфлоу в остановленную
сборку» попадают куда надо даже тогда, когда ваш профиль переносит эти
папки в другое место.
