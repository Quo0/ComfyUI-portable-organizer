# Справочник

Что приложение пишет, куда пишет и что передаёт ComfyUI. Этот раздел
существует, чтобы приложение можно было проверить, а не принимать на веру.

- [Какие флаги мы добавляем](/ru/reference/flags) — три флага командной
  строки и зачем каждый.
- [instances.json](/ru/reference/instances-json) — формат реестра сборок.
- [Профили запуска](/ru/reference/launch-profile) — как `.bat`-файл
  становится профилем.
- [Генерируемый YAML](/ru/reference/extra-model-paths) — конфиг общих
  моделей, который мы производим.

## Где что лежит

| Путь | Что |
| --- | --- |
| `%APPDATA%\io.github.quo0.comfyui-organizer\settings.json` | Настройки: тема, язык, общие модели, путь к библиотеке |
| `%APPDATA%\io.github.quo0.comfyui-organizer\instances.json` | Реестр сборок |
| `%APPDATA%\io.github.quo0.comfyui-organizer\shared-models.yaml` | Сгенерированный конфиг, в режиме флага |
| `%LOCALAPPDATA%\io.github.quo0.comfyui-organizer\` | Снимки нод по сборкам, данные WebView2 |
| `<библиотека>\_library.json` | Теги, заметки, избранное — внутри вашей библиотеки, а не здесь |

Всё это обычный текст. Ничто о ваших сборках больше нигде не хранится,
и в реестр Windows не пишется ничего, кроме записи о деинсталляции,
которую заводит инсталлятор.
