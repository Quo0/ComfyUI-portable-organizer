# Какие флаги мы добавляем

Приложение запускает `python.exe` напрямую, с аргументами, разобранными
из профиля, плюс не более трёх своих. Итоговую командную строку видно
в редакторе аргументов до того, как что-либо запустится.

## `--port <n>`

Порт назначает приложение: предпочитаемый порт сборки, если он свободен,
иначе следующий свободный.

Любой `--port`, уже присутствующий в профиле, удаляется **вместе
со значением**, в обоих написаниях (`--port 8188` и `--port=8188`). Две
сборки с одним жёстко заданным портом означали бы падение второй при
старте по причине, на вид никак не связанной с тем, что вы делали.

## `--disable-auto-launch`

Чтобы запуск сборки не открывал вкладку браузера.

Это работает без всякого патчинга — из-за порядка внутри собственного
разбора аргументов ComfyUI (`comfy/cli_args.py`):

```python
if args.windows_standalone_build:
    args.auto_launch = True
if args.disable_auto_launch:
    args.auto_launch = False
```

Отключающий флаг применяется вторым и всегда побеждает, так что дописать
его в командную строку достаточно.

## `--extra-model-paths-config <путь>`

Добавляется только когда сборка подключена к общей папке моделей в
**режиме флага**. Путь указывает на конфиг в собственной папке данных
приложения, который перегенерируется при каждом изменении настроек.

`--extra-model-paths-config`, уже присутствующий в профиле, **не**
трогается. Флаг накапливается (`nargs='+'`, `action='append'`), а ComfyUI
загружает сперва `ComfyUI/extra_model_paths.yaml`, потом файлы из флага,
так что наш дополняет ваш, а не заменяет его.

В режиме «файл внутри сборки» флаг не добавляется вовсе: файл лежит
в папке сборки, и ComfyUI подхватывает его сам.

## Чего мы не добавляем никогда

- `--enable-cors-header`. Он позволил бы встроить ComfyUI в `<iframe>` —
  и заодно полностью отключает межсайтовую защиту ComfyUI, то есть любой
  открытый у вас в браузере сайт смог бы говорить с вашим локальным
  сервером. Вместо этого приложение использует нативное дочернее окно,
  которое собственная прослойка ComfyUI принимает за обычную навигацию
  верхнего уровня.
- `--listen`. Сервер остаётся на `127.0.0.1`.
- Всё, что меняет пути к моделям помимо конфига выше.
