# Какие флаги мы добавляем

Приложение запускает `python.exe` напрямую — с аргументами, разобранными
из профиля, и не более чем тремя своими. Итоговую командную строку видно
в редакторе аргументов ещё до запуска.

## `--port <n>`

Порт назначает приложение: предпочитаемый порт сборки, если он свободен,
иначе следующий свободный.

`--port`, который уже есть в профиле, удаляется **вместе со значением**,
в обоих написаниях (`--port 8188` и `--port=8188`). Иначе две сборки
с одним и тем же жёстко заданным портом приводили бы к тому, что вторая
падает на старте по причине, на вид никак не связанной с тем, что вы
делали.

## `--disable-auto-launch`

Чтобы запуск сборки не открывал вкладку браузера.

Это работает без всякого патчинга — просто из-за порядка строк
в собственном разборе аргументов ComfyUI (`comfy/cli_args.py`):

```python
if args.windows_standalone_build:
    args.auto_launch = True
if args.disable_auto_launch:
    args.auto_launch = False
```

Отключающий флаг применяется вторым и всегда побеждает, так что дописать
его в командную строку достаточно.

## `--extra-model-paths-config <путь>`

Добавляется, только когда сборка подключена к общей папке моделей
в **режиме флага**. Путь ведёт к конфигу в собственной папке данных
приложения; конфиг пересобирается при каждом изменении настроек.

`--extra-model-paths-config`, который уже есть в профиле, мы **не**
трогаем. Этот флаг можно указывать несколько раз (`nargs='+'`,
`action='append'`), а ComfyUI загружает сперва
`ComfyUI/extra_model_paths.yaml`, потом файлы из флага, так что наш
конфиг дополняет ваш, а не заменяет его.

В режиме «файл внутри сборки» флаг не добавляется вовсе: файл лежит
в папке сборки, и ComfyUI подхватывает его сам.

## Чего мы не добавляем никогда

- `--enable-cors-header`. С ним ComfyUI можно было бы встроить
  в `<iframe>` — но заодно он полностью снимает межсайтовую защиту
  ComfyUI, и тогда любой открытый у вас в браузере сайт смог бы говорить
  с вашим локальным сервером. Вместо этого приложение показывает ComfyUI
  в нативном дочернем окне, которое его собственная прослойка принимает
  за обычную навигацию верхнего уровня.
- `--listen`. Сервер остаётся на `127.0.0.1`.
- Всё, что меняет пути к моделям помимо конфига выше.
